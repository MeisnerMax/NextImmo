# PH-01 Owner Decisions

Stand: 2026-08-02  
Status: `accepted`

| ID | Entscheidung |
| --- | --- |
| `AI-PH01-DEC-001` | Frankfurt/EU ist Zielregion. Remote-Provisionierung, Credentials und Kosten bleiben separat freigabepflichtig. |
| `AI-PH01-DEC-002` | AAL2 ist fuer privilegierte Capabilities und jede Proposal-Annahme erforderlich. `ai.use` ersetzt kein Domainrecht. |
| `AI-PH01-DEC-003` | Entity-Scope ist eine explizite `property`-/`portfolio`-Allowlist. Vorhandene Scopes schraenken den Workspacezugriff ein; unbekannte Typen sind Deny. |
| `AI-PH01-DEC-004` | Bis zur fachlich-juristischen Freigabe werden keine produktiven PII an einen Provider uebertragen und keine Daten automatisch physisch geloescht. |

Diese Entscheidungen autorisieren lokale, reversible PH-01-Arbeit. Sie autorisieren kein
Deployment, keine Remote-Ressource und keinen Live-Provider-Aufruf.
